# Bank logo provenance

One-time vendor from Wikimedia Commons (dev-only scripts in
/data/workspaces/kernel/staging/sure-dev/round16-bank-logo-vendor/: vendor.rb
for in-container runs, vendor_host.py for host-egress runs; shared manifest.json).
License gate: LicenseShortName "Public domain" or a CC0 1.0 Universal Public
Domain Dedication long name ONLY. Every Commons logo file carries a trademark
disclaimer; use here is nominative (a personal, non-commercial app
identifying the bank of the owner's own accounts). Served same-origin by
Rails; the app never fetches logos at runtime.

2026-11-02 (P3-f): lockups replaced with icon-only marks for sankey chips (14px draw size).
Originals recoverable at git HEAD 1ef7aac. "Icon" column records how each file was produced.
