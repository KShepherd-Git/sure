# Bank logo provenance

One-time vendor from Wikimedia Commons (one-off scripts: vendor.rb for
in-container runs, vendor_host.py for host-egress runs; shared manifest.json).
License gate: LicenseShortName "Public domain" or a CC0 1.0 Universal Public
Domain Dedication long name ONLY. Every Commons logo file carries a trademark
disclaimer; use here is nominative (a personal, non-commercial app
identifying the bank of the user's own accounts). Served same-origin by
Rails; the app never fetches logos at runtime.

2026-11-02: lockups replaced with icon-only marks for sankey chips (14px draw size).
Originals recoverable at git HEAD 1ef7aac. "Icon" column records how each file was produced.

2026-11-06: two monogram fallbacks replaced with the REAL vendored
lockups (same PD Commons sources, no new fetch needed — files recovered from git
1ef7aac): navy-federal (no separate icon mark exists for this brand; the full
wordmark is the mark, centered on a square 48x48 canvas so the circular chip and
32px avatars render it uncropped) and american-express (the original 300x300
blue-box logo, restored byte-identical). Remaining monogram fallbacks stay as-is:
no live account resolves to them.
